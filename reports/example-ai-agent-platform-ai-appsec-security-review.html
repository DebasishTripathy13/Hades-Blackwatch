1. Agent web fetch tool can receive model-controlled URLs

High Confidence: high

Affected Component

Affected File

src/tools/fetch_url.ts

Affected Endpoint

Affected Asset

internal network reachable by agent runtime

Evidence

{
  "summary": "The fetch tool accepts an arbitrary URL from the agent planner without a deterministic host allowlist or private IP block.",
  "rule_id": "custom-ai-ssrf"
}

Attack Path

A prompt injection causes the model to call the fetch tool with an internal metadata or service URL. The tool performs the request from the trusted runtime.

AI / Agent Relevance

The LLM is not a trusted policy enforcement point. Prompt or RAG injection can influence tool parameters unless deterministic validation exists before network access.

Threat Intelligence

As of 2026-05-28

This finding maps to a common agentic exploit pattern: prompt injection or compromised context influences a network-capable tool, turning an AI workflow into an SSRF path.

  • Prompt injection to tool abuse: The vulnerable tool trusts model-selected URLs rather than a deterministic network policy. Action: Block private and link-local ranges after DNS resolution, require allowlists, and log denied attempts.

Mapped Techniques

{
  "mitre_atlas": "Prompt injection and tool abuse pattern",
  "cwe": "CWE-918"
}

Detection / Test Impact

Add a regression test that attempts metadata-service and RFC1918 URLs through the agent tool and asserts denial before outbound network access.

Attack Path Visualization

How Prompt Influence Can Become Agent SSRF

The risk is not that the model is malicious by itself. The risk is that untrusted prompt or retrieved context can steer a network-capable tool unless deterministic URL policy checks happen outside the model.

1 Prompt Influence

Untrusted content influences the agent planner.

Actor: External user or poisoned contextGap: The prompt is treated as trusted instruction.Break: Classify external prompt and retrieved content as untrusted.
2 Tool Selection

The planner selects the web fetch tool with a model-controlled destination.

Actor: Agent runtimeGap: Tool parameters rely on model judgment.Break: Validate tool parameters before execution.
3 Network Boundary

The runtime attempts outbound access from a trusted network position.

Actor: Fetch toolGap: No allowlist or private IP block after DNS resolution.Break: Block private, reserved, and link-local ranges.
4 Impact

Internal services or metadata endpoints may become reachable through the agent.

Actor: Protected assetGap: Runtime egress is too broad.Break: Restrict egress and require approval for new domains.
5 Detect / Break

Denied URL attempts should be logged and covered by regression tests.

Actor: Security controlGap: No test proves the unsafe request is blocked.Break: Add CI tests and runtime detections for blocked destinations.

Attacker Goal

Cause the agent runtime to request an internal or otherwise unauthorized URL.

Preconditions

The attacker can influence prompt, chat, document, or workflow context that reaches the agent planner.

Control Breaks

Missing deterministic URL policy enforcement outside the LLM.

Impact

Internal network reachable by the agent runtime.

Detection Points

Denied requests to private, reserved, link-local, and metadata ranges.

Defensive Breakpoints
